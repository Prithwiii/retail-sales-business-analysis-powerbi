# Retail Sales Business Analysis

Interactive Power BI dashboard for exploring retail sales performance, revenue trends, customer behavior, and discount effects.

## What’s included

- `dataset/store_sales.csv` — retail sales dataset
- `powerbi/retail-sales-business-analysis.pbix` — Power BI report
- `images/` — screenshots of the dashboard

## Overview

This project analyzes:

- sales and revenue by product, region, and time
- customer purchasing patterns
- discount impact on sales
- store performance trends

## How to use

1. Open the `.pbix` file in Power BI Desktop.
2. Load the dataset from `dataset/store_sales.csv` if needed.
3. Explore the report visuals and filters to review performance trends.
